## ✨ About

ShiraOS is a custom shell/UI project focused on aesthetics, productivity, blur effects, dynamic widgets, animations, and a modern Linux experience built around Hyprland + Quickshell.

## 🚀 Features

* Dynamic topbar / widgets
* Blur & transparency effects
* Wallpaper integration
* Accent color extraction
* Music / media modules
* Minimal + futuristic design
* Fast and customizable workflow

## 🛠️ Stack

* Hyprland
* Quickshell
* Qt6 / QML
* Bash
* Python
* Linux / Arch-based distros
